ZiUPX Recon Framework

Профессиональный OSINT-инструмент для сбора информации из открытых источников. Написан с нуля на Python. 

ЧТО ЭТО?
ZiUPX Recon Framework — это модульная система для разведки (OSINT). В отличие от простых скриптов, здесь каждый тип проверки вынесен в отдельный модуль. Это позволяет легко добавлять новые функции и получать чистый, структурированный отчет.

ВОЗМОЖНОСТИ:
- Поиск по Email: Проверка активности почты через Gravatar и поиск привязанных аккаунтов на GitHub.
- Поиск по Никнейму: Проверка существования профилей в Telegram, TikTok и GitHub по заданному имени пользователя.
- Профессиональный вывод: Строгий дизайн интерфейса, цветовые маркеры статусов и удобные таблицы с результатами.
