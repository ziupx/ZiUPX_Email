# ZiUPX Email Detective
© 2026 ZiUPX Team

Профессиональный OSINT-инструмент для расследования email-адресов. Написан с нуля на Python.

## В чем фишка?
Email-адрес — это уникальный цифровой след. Этот инструмент собирает информацию об email из открытых источников и проверяет, не был ли он скомпрометирован.

## Возможности:
- **Проверка утечек:** Поиск в публичных базах данных.
- **Проверка регистраций:** Наличие аккаунта на GitHub.
- **Проверка Gravatar:** Определение активности email.

Дисклеймер

Данный инструмент создан исключительно в образовательных целях. Используйте его только для проверки своих собственных email-адресов или адресов, на обработку которых у вас есть официальное разрешение.
